# Result-Intro · 结果中心组导读

> 返回 [Home](Home) ｜ 上一页：[BEAST](BEAST) ｜ 下一页：[Results](Results)

本组是全平台产物的统一查看出口：分析跑完后回到这里看产物、看报告、排图版。共 4 篇专页。

## 模块清单

1. [Results](Results) · 样品结果 / 专项结果 —— 结果中心页：样品结果树、专项运行列表、文件下载、各查看器入口，结果都会回到这里。
2. [Report](Report) · 可视化报告（管线 ⑩）—— 单文件 HTML 报告（Plotly 全离线）加漏斗图 / 基因组图，样品级汇总。
3. [Svguest](Svguest) · 结果图整理 —— 本地 SVG 编辑器：多图合并 / 排版 / 标注 / 比例尺，导出 PNG · SVG · PDF，文件不上传。
4. [Result-Interpretation](Result-Interpretation) · 结果判读规则 —— known / novel 阈值、SDT / identity 口径、时间信号解读、审计交付模板与写作避坑。

## 链路

分析产物 → [Results](Results) 汇总查看 → [Report](Report) 样品级图表报告 → [Svguest](Svguest) 图版排版。写报告或论文时，按 [Result-Interpretation](Result-Interpretation) 的数字化判据表定结论。
