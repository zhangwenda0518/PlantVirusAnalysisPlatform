# LAMP 引物组设计正确性验证报告

日期：2026-11-05 ｜ 引擎：Virus_Platform_Core/lamp_design.py 1.0.0
验证脚本：tests/_check_lamp_correctness.py（可重复执行）

## 一、验证方法

**独立复核原则**：验证脚本不调用引擎内部校验函数，全部用自带实现重算——
序列回取用源 FASTA、GC 用纯算术、Tm 用 Biopython MeltingTemp.Tm_NN
（独立热力学库）、二聚体用独立滑窗实现。避免"自己验自己"。

**数据**：examples/example_acmv.fasta（非洲木薯花叶病毒 DNA-A，2779bp，
平台内置示例）——与示例结果 examples/results/lamp/ 同源。

## 二、验证结果（5 组 × 38 项 = 190 项 + anchor 2 项，全部 PASS）

| 验证项 | 方法 | 结果 |
|---|---|---|
| 序列坐标回取 | 输出坐标为 1 基，回源序列逐字节对比 | 30/30 一致 |
| GC% | 独立算式重算 | 30/30 一致（Δ≤0.2） |
| Tm 区间 | 各段落在设计目标区间（外 59.5-62.5 / 内 61.5-65.5 / F1/B1 63.5-66.5） | 30/30 合规 |
| **Tm 双模型互证** | **Biopython Tm_NN（Na50/Mg1.5/dNTP0.8）独立重算 vs primer3** | **Δ=+1.3~1.5°C（≤2.5 容差）** |
| FIP 拼接 | revcomp(F1区)+TTTT+F2区 精确匹配 | 5/5 |
| BIP 拼接 | B1区+TTTT+revcomp(B2区) 精确匹配 | 5/5 |
| 五段间距 | F3-F2≤20 / F2-F1 10-40 / F1-B1 40-120 / B1-B2 10-40 / B2-B3≤20 | 25/25 合规 |
| F2-B2 产物 | = b2_start − f2_end + 1，落在 120-180 | 5/5 合规 |
| 段序 | F3<F2<F1<B1<B2<B3 正链不重叠 | 5/5 |
| Tm 秩序 | 外引物（F3/B3）均值 < 内引物（F2/B2/F1/B1）均值 | 5/5（如 60.6 < 63.6） |
| 二聚体 QC | 独立滑窗实现重算自二聚 vs 输出 | 5/5（Δ=0.0） |
| anchor 约束 | 锚区间必须被 F2-B2 产物包住 | 可行位点全过；不可行位点如实返回空 |

**关键证据（Tm 双模型互证）**：primer3 calc_tm 与 Biopython Tm_NN 是两套
独立最近邻热力学实现。盐条件对齐（mv 50mM / Mg 1.5mM / dNTP 0.8mM）后，
六段引物的 Tm 偏差恒定为 +1.3~+1.5°C——系统口径差在 ±2°C 内，证明引擎的
Tm 取值正确而非自证。作为对照：若改用 LAMP 实测体系盐（Mg 8mM），两模型
偏差系统性上移到 +6.1°C（有效盐抬升），**这是口径差不是计算错误**——设计
选段用的是 primer3 口径，全部落在目标区间。

## 三、边界行为验证

- **锚不可行**：ACMV 1200-1400 区间在 F2 的 Tm 约束下无候选（该区 Tm 不
  达标），锚 @1400 时产物下限数学上必超 180bp → 引擎返回 0 组。经逐层
  插桩确认是**数据约束下的真实不可行**（F2 end∈[1241,1399] 候选数 = 0），
  非程序缺陷；锚 @200/@600 均正常出组（6/15 组）。
- **保守过滤**：保守分传参全 0 时返回空（段窗 min 约束生效）。
- **环引物开关**：use_loop=0 时输出不含 LF/LB。
- **探针铁律**：crispr --amp LAMP 时 RPA 探针强制 none。

## 五、证据边界

计算设计仅支持候选优先级排序，不构成扩增效率、引物间干扰或基质性能的
证据；实验结论须按 L1-L5 逐级建立（65°C Bst 酶体系、内外引物浓度比、
环引物增益需实验验证）。本报告验证的是**规则与数值的自洽性**（设计输出
忠实执行了声明的约束），不是 LAMP 反应本身的性能。
