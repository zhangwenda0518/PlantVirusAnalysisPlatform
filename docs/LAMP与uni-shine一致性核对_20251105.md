## 五、本轮核对中发现并修复的 3 个真实问题

1. **Tm 区间过窄**（每段 3°C）：多分离物 MSA 保守过滤后候选变稀，组装链
   在 6613bp 共识上全断（ORSV 0 组）。对齐 uni-shine 的 9-10°C 宽区间
   （target 仅作排序）后恢复 40 组。
2. **骨架截断/候选截断策略**：全局按 dev 截断 600 导致不同 Tm 段的 top
   候选位置互斥（f3 窗 100% 失败）→ 改位置分桶保留（每 100bp 取 dev
   最优 15 个），同时骨架对上限 40→120。
3. **性能**：`_tm` 每调用走 primer3 探测（0.81ms → 缓存后 0.002ms，
   400 倍）；骨架枚举 O(n) 预筛改 bisect；6613bp 设计 2-4 秒。

## 六、结论

- **结构一致性**：六引物组、外低内高 Tm 段序、FIP/BIP 拼接、间距机制
  两引擎完全一致
- **位点互认**：同一靶标上两引擎的设计位点重叠到 11bp 内
- **MAFFT 互认**：我们的 5 分离物 MAFFT 共识直接作为它的输入，正常出
  31 passed QC——MSA 产物格式与质量双兼容
- **差异均为口径差**（Tm 盐条件、产物区间严格度、linker 写法、排序偏好），
  非算法分歧

## 七、差异归因（为什么同一位置两边的具体参数不同）

同位置对照（ORSV 共识，两边在同一区段 5055-5337 各取一组）：

| 项 | 我们（f3@5067 组） | uni-shine（Set#1） | 直接原因 |
|---|---|---|---|
| F3 | 5067 / 22nt / 60.77°C | 5055 / 20nt / 57.2°C | 选窗不同 + **外引物 Tm 目标不同**（我们 60.5，它 58） |
| F2 | 5091 / 19nt / 61.5°C | 5098 / 21nt / 64.1°C | 同上（内目标 63.5 vs 62，盐口径差） |
| F1c | 5120 / 24nt / 64.65°C | 5182 / 22nt / 66.1°C | **间距上限差异**（我们 F2-F1 ≤40，它允许 64） |
| B1c | 5210 / 24nt / 60.9°C | 5241 / 22nt / 66.2°C | 同上 |
| B2 | 5259 / 17nt / 60.92°C | 5307 / 21nt / 64.1°C | 同上 |
| B3 | 5312 / 22nt / 60.58°C | 5337 / 20nt / 57.6°C | 同上 |
| **产物（F2-B2）** | **150bp** | **~230-250bp** | **产物区间约束：我们 120-180（窄），它 100-500（宽）** |

### 五项差异的机制归因

1. **产物区间是"位置/间距差异"的总根源**：它的 Amplicon 允许
   100-500bp → 段间距可以铺开到 24-64bp；我们 120-180 → 产物 ≤180，
   间距被迫紧凑（F3-F2 2-3 / F2-F1 10 / B2-B3 36）。PSTVd 的"我们多、
   它少"也源于此：359bp 上它的 100-500 可行域被 F3-F2≤60 严格模式
   压缩，我们的 120-180 反而贴合小分子。
2. **Tm 目标体系不同**：它 外 58 / 内 62 / 中 64（内外差 6-8°C，外引物
   明显偏低）；我们 外 60.5 / 内 63.5 / 中 65（差 3-4.5°C，文献的
   "外低 2-3°C"窄差口径）。绝对差 ~6°C 仍是 Tm 计算盐条件
   （它高盐体系 / 我们 primer3 50mM）。
3. **评分体系不同**：它 Score 0-10 + penalty 分解（含 3'dG、ML 排序
   可选）；我们 0-100（Tm 偏差 + 间距偏差 + 二聚体 + 锚加成）。同一
   位置它的组排第一、我们排中上（72.5）——因为该组在我们口径下
   Tm 偏离目标较多（B1 60.9 vs 目标 65），评分偏好不同所致。
4. **sets 上限口径**：它 Max Sets 2000 生成、UI 展示/保存前 50
   （"85 passed QC / 50 sets" = QC 通过 85 个、展示 50 个）；我们返回
   全部候选组（run_chain 按 top_n 截断到 20）。
5. **QC 严格度**：它 QC 二聚体/3'dG 硬性判定（31/50 有警告仍展示）；
   我们 qc 软罚分（不 veto，排序承担）。

### 结论

所有差异都可归到 **4 个参数/设计选择（产物区间、Tm 目标体系、评分
偏好、sets 上限）+ 1 个盐口径**，无算法分歧。两边在"同一位置是否
可设计"上互认（11bp），差异只是"在可设计空间里各选各的偏好点"。
